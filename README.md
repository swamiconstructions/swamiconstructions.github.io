# Swami Constructions website

A responsive, static business website for Swami Constructions, Shegaon, Maharashtra. Built with HTML, CSS and vanilla JavaScript. No backend, paid theme, build step or package installation is required.

## Preview locally

1. Extract this folder.
2. Double-click `index.html` to open it in a browser, or use VS Code Live Server.
3. Test the navigation, gallery links and enquiry form on desktop and mobile widths.

The enquiry form opens WhatsApp with a pre-filled message. It does not store data or send information to a database.

## Publish free with GitHub Pages

Recommended repository name: `swami-constructions`.

1. Create a **public** repository on GitHub named `swami-constructions`.
2. Upload the contents of this folder to the repository root. Make sure `index.html`, `styles.css`, `script.js` and `assets/` are at the root level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. GitHub will publish the site at a URL similar to `https://YOUR-GITHUB-USERNAME.github.io/swami-constructions/`.

Because this is a project site, keep the relative asset paths as they are. A custom domain is optional and usually costs money to register.
